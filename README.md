## 🎯 2) COURSE FOLDERS
There are 4 courses in this Nanodegree. There is one folder for each course. \
Each `course` folder is named using the naming convention of `c#_name_of_the_course`. \
Example
```
c1_model_optimize_foundation : course 1
c2_advanced_model_compression : course 2
c3_efficient_architecture: course 3
c4_llm_inference_optimize: course 4
```

## 🎯 3) PROJECT FOLDERS
Each `course` could have a project.
Example
``` 
project_c1_ksw: this is my solution to the project in course 1. 
```

The project folders are at the root level for easy accessibility
