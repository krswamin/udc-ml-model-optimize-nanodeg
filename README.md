# 🎯 Udacity:  ML Model Optimization Nanodegree

This repo is an implementation of the code lessons and projects in the course : Udacity Machine Learning Model Optimization Degree
- the base lessons and project starters have been forked from the udacity machinel learning optimization nanodegree github repos. There were likely different repos for each of the 4 courses and 4 projects. I have put them all under one repo here
- there are demo code solutions, exercise code solutions , project code solutions and several readmes that I've developed on top of the udacity base files. Those are in this repo too

## 🎯 2) COURSE FOLDERS
There are 4 courses in this Nanodegree. There is one folder for each course. \
Each `course` folder is named using the naming convention of `c#_name_of_the_course`. \
Example
```
c1_model_optimize_foundation : course 1
c2_advanced_model_compression : course 2
c3_efficient_architecture: course 3
c4_llm_inference_optimize: course 4
```

## 🎯 3) PROJECT FOLDERS
Each `course` could have a project.\
The project folders are at the root level for easy accessibility \
Example
``` 
project_c1_ksw: this is my solution to the project in course 1. 
```
